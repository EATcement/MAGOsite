# Criador de fichas para RPG em pdf

Um sistema em Python para criação e gerenciamento de fichas de RPG, inspirado em D&D.

O projeto começou como um experimento pessoal para facilitar a criação de personagens e gerar fichas em PDF, mas acabou reunindo outras ferramentas úteis para uma campanha de RPG.

## Funcionalidades

- Criação de fichas de personagem
- Edição e carregamento de fichas
- Geração de fichas em PDF
- Criação de fichas de monstros
- Inventário e controle de ouro
- Rolagem de dados (D4, D6, D8, D10, D12 e D20)
- Histórico de rolagens
- Diário de aventura com exportação para PDF
- Gerador de nomes de personagens, monstros e lugares
- Ferramentas voltadas para jogadores e mestres

## Tecnologias

- Python
- FPDF / fpdf2
- Pickle

## Como executar

Clone o repositório e instale a dependência necessária:


pip install fpdf2

Depois, execute:
python menu_principal.py


A partir do menu principal é possível acessar as diferentes ferramentas do sistema.

## Sobre o projeto

Este foi um dos nossos primeiros projetos em Python e teve um caráter principalmente criativo e experimental. Por isso, a estrutura do código não segue uma arquitetura totalmente padronizada, mas foi um projeto importante para aprender conceitos de programação, modularização, manipulação de arquivos, geração de PDFs e criação de sistemas interativos em Python.
